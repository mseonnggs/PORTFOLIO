# 로컬 검증 기록

2026.11.02 · http://127.0.0.1:4173 · Playwright + 실제 설치된 Chrome headless.

## 실행 명령

`npm.cmd run check`, `node --check app.js`, `node --check scripts/server.cjs`, `npm.cmd test`, `npm.cmd run build`.

## 확인 범위

- 18페이지 목차·이전/다음·좌우 키·해시 직접 접속·진행률·첫/마지막 버튼 상태.
- PC 1024×768, 1440×1000, 1920×1080: 모든 페이지의 16px 미만 글자·가로 넘침·본문 너비 초과 검사.
- 모바일·태블릿 360×800, 390×844, 768×1024: 전체 세로 읽기, 목차 열기·이동·닫기, 현재 위치, 문서 끝 마지막 페이지 상태, 16px 미만 글자와 가로 넘침 검사.
- 실제 꼬리별지도 전체 캡처: 확대 대화상자·긴 이미지 스크롤·ESC/닫기 버튼·트리거 포커스 복귀. 모바일에서도 확대·스크롤 가능 여부·포커스 복귀 확인.
- 교체 기능: 테스트에서만 실제 꼬리별지도 긴 캡처를 상세페이지 슬롯에 넣어 전체 보기 확인. 존재하지 않는 이미지 경로도 테스트 데이터로만 주입해 준비 중 표시로 대체되는지 확인. 이 주입 데이터는 `data.json`이나 빌드에 저장하지 않음.
- 로컬 Pretendard 파일이 네트워크 리소스로 로드되고 브라우저 글꼴 등록이 완료되는지 검사.
- 모션 줄이기 설정에서 전환 효과 제거.
- 이력서·분석 문서·개발 파일이 로컬 HTTP 서버에서 노출되지 않는지 검사. 업무 이메일·전화, 꼬리별지도·PulseHealth 실제 URL, 원본 프로젝트 PDF 2개의 HTTP 200·PDF 헤더·파일 시그니처 확인.
- `data.json` 자료 연결·파일 존재·미분류 회사 유지·원본 뉴스룸 수치/개인 주소·생년·연봉 제외 검사.
- PC 표지·회사 작업물·꼬리별지도, 모바일 표지·회사 작업물 스크린샷을 저장하고 시각 확인.

## 확인 제한과 남은 보완

- 회사별 인쇄물·사진·사인 대부분은 원본 미확보로 교체 구조만 확인. RTM 상세페이지는 실제 1200×27436px 원본으로 대표 영역·전체 보기·길이·스크롤을 확인.
- 프로젝트 PDF 2개를 분석하고 실제 링크·파일 제공을 확인. 꼬리별지도 지도는 PDF의 화면 예시라는 표기를 유지. PulseHealth 캡처도 PDF 원본에서 추출한 실제 구현 화면으로 연결.
- 프로젝트 기능 설명은 제공 PDF를 근거로 정리했으며 두 프로젝트 전체의 기능을 새로 회귀 검증한 것은 아님. 기존 PDF의 수치도 이번 포트폴리오의 검증 결과로 소개하지 않음.
- 꼬리별지도 공개 화면과 검색·조건 UI를 확인. 로그인 기반 저장·지도 기능은 제공 PDF의 구현 범위를 설명하며 이번 작업에서 로그인 계정으로 재검증하지 않음.
- 검증 브라우저는 Chrome이며 Safari·Firefox·실물 스마트폰 검증은 수행하지 않음.
- `test-results/results.json`의 결과는 이번 포트폴리오 구현 테스트이며, PulseHealth 기존 프로젝트의 테스트 결과가 아님.

## 산출물

새 표지 검증: `tests/cover.cjs`에서 360·390·768·1024·1440·1920px 화면을 확인합니다. 사진의 원본 크기·비율·흑백 표시, 타이틀 폰트 로드, 키워드·타이틀·사진의 겹침과 잘림, ‘장미선’의 하강 모션·최종 포인트 컬러, 모션 줄이기, 표지와 기존 About Me의 연결을 검사합니다. PC·모바일 표지 캡처는 `test-results/cover-1440.png`, `cover-390.png`에 저장합니다. 표지에서는 자체 About Me 링크를 제공하며, 기존 떠 있는 About Me 화살표는 다음 섹션부터 표시해 작은 화면의 키워드를 가리지 않게 합니다.

부드러운 스크롤 변경 검증: `tests/scrolling.cjs` 7개 검사 그룹 통과. 실제 스크롤 좌표를 프레임별로 기록해 중간 이동과 가속·감속을 확인했습니다. 메뉴·버튼·방향키, 긴 거리 이동, 연속 요청의 최종 목적지, 휠 중단과 수동 스크롤의 활성 메뉴, 화면 크기 변경, 모바일 헤더 여백·맨 위로, 모션 줄이기 설정, 해시 직접 진입 위치를 확인했습니다. `test-results/scrolling.json`과 `test-results/scroll-samples.json`에 결과를 저장합니다. 일반 콘텐츠 검사는 모션 줄이기 상태에서, 별도 스크롤 검사는 실제 애니메이션 상태에서 실행합니다. 콘텐츠·이미지의 가로 넘침과 확대 검증은 그대로 유지합니다.
